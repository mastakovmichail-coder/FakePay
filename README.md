# FakePay — симулятор эквайринга

Фейковый платёжный терминал: **реальные деньги и карты не участвуют**. Нужен для отладки и демонстраций.

```
 ┌──────────────┐        ┌──────────────┐        ┌──────────────────┐
 │ ПК-касса     │◄──────►│ Релей-сервер │◄──────►│ Телефон-терминал │
 │ (Electron)   │  WS    │ (Node.js)    │  WS    │ (APK, Capacitor) │
 └──────────────┘        └──────────────┘        └──────────────────┘
   вводит код + сумму      сопоставляет код        генерирует код при
   видит журнал            и пересылает платежи    каждом запуске
```

## Самый простой путь (два батника)

| Что нужно | Что запустить | Результат |
|-----------|---------------|-----------|
| Установщик ПК-кассы | `build-windows.bat` | `dist\FakePay-POS-Setup.exe` — обычный установщик (Inno Setup) |
| APK для телефона | `upload-github.bat` | проект на GitHub, APK собирается сам во вкладке **Actions** |

**`build-windows.bat`** — нужен только Node.js LTS. Сам соберёт приложение, найдёт Inno Setup (если его нет, поставит через `winget`; иначе скачайте с jrsoftware.org), создаст установщик и предложит его запустить. В установщике есть галочка «разрешить порт 8787 в брандмауэре» — чтобы телефон мог подключиться. Сервер встроен в приложение: отдельно запускать `node server.js` не нужно, адрес для телефона программа покажет в журнале.

**`upload-github.bat`** — нужен Git. Создайте на github.com пустой репозиторий (без README), запустите батник и вставьте его адрес (или нажмите Enter, если установлен GitHub CLI `gh` — репозиторий создастся сам). После отправки откроется вкладка **Actions**: запустится сборка «Build APK» (5–10 минут), по её завершении в нижней части страницы запуска, в разделе **Artifacts**, появится **FakePay-Terminal-apk** (внутри `.apk`). Повторная сборка: Actions → Build APK → Run workflow. APK подписан отладочным ключом, для установки включите на телефоне «Установка из неизвестных источников».

## Как это работает

1. Запускаете сервер.
2. Открываете приложение на телефоне — оно показывает **новый 6-значный код** (создаётся при каждом запуске).
3. В ПК-программе вводите код → касса подключается к этому терминалу.
4. Вводите сумму → «Оплатить». На телефоне появляется запрос, нажимаете на карту → в журнале на ПК:
   **«Оплата прошла успешно!»**. Можно «Отклонить» на телефоне или «Отмена» на ПК.

## Быстрый старт

### 1. Сервер (зависимостей нет, нужен Node.js 22+)
```bash
cd server
node server.js          # ws://0.0.0.0:8787
node test.js            # автотест протокола (по желанию)
```

### 2. ПК-приложение
```bash
cd desktop
npm install
npm start               # запуск
npm run dist            # сборка установщика .exe (Windows)
```
В поле «Адрес сервера» укажите `ws://localhost:8787` (если сервер на этом же ПК).

### 3. Телефон (APK)
Нужны Node.js, Android Studio (или Android SDK + JDK 17).
```bash
cd mobile
npm install
npx cap add android
node setup-android.js   # подключает NFC-плагин и разрешение NFC (обязательно для оплаты по касанию)
npx cap sync android
npx cap open android    # откроется Android Studio → Build → Build APK(s)
```
APK будет в `android/app/build/outputs/apk/debug/`. После установки нажмите ⚙ и укажите адрес сервера.
Если уже делали `cap add android` раньше — достаточно `node setup-android.js` и `npx cap sync android`.

**Быстрая проверка без APK:** откройте `mobile/www/index.html` в браузере телефона/ПК (лучше через любой статический сервер). NFC там не сработает, но платёж проходит нажатием на карту на экране.

## Оплата по NFC

Когда на телефон приходит запрос оплаты, терминал включает NFC и **проходит оплату при касании любой NFC-карты, метки или другого телефона**. Касания вне запроса оплаты игнорируются.

- Данные карты **не читаются** — приложение лишь фиксирует факт касания (даже ID метки не запрашивается). Это сделано намеренно: симулятор не должен работать с реальными данными карт.
- Нужен телефон с NFC, включённый в настройках Android. Если NFC выключен или его нет, на экране появится подсказка, а оплатить можно нажатием на карту.
- Отключить можно в ⚙ → «Оплата по NFC».
- Под запросом оплаты видна строка состояния: «NFC активен (нативный)» — всё работает; «NFC-плагин не найден в этой сборке APK» — APK собран без `setup-android.js`, пересоберите (повторно запустите `upload-github.bat`); «NFC выключен в настройках телефона» — включите NFC в Android.
- Ошибка `NDEFReader … permission request denied` означала, что приложение пыталось использовать Web NFC вместо нативного плагина. В APK Web NFC не работает (WebView не показывает запрос разрешения), поэтому теперь такой откат внутри APK отключён.
- Реализация — небольшой нативный плагин `mobile/native/NfcTapPlugin.java` (Android Reader Mode), его подключает `setup-android.js`.

## Тестовые отказы и история

- ⚙ на телефоне → «Случайные отказы, %»: заданная доля платежей будет отклоняться с причиной «Недостаточно средств (тест)».
- В ПК-программе вкладка **«История»** хранит последние 500 операций (сохраняется между запусками), статистика считается по ней, есть **экспорт в CSV** (открывается в Excel).

## Адрес сервера

- **Одна Wi-Fi сеть:** узнайте IP компьютера с сервером (`ipconfig`) и укажите `ws://192.168.x.x:8787` и на ПК, и на телефоне. Разрешите порт 8787 в брандмауэре Windows.
- **Через интернет:** разместите `server/` на любом VPS/хостинге с Node.js и укажите `ws://ваш-домен:8787`. Для `wss://` поставьте перед сервером nginx/Caddy с HTTPS.

## Протокол (JSON поверх WebSocket)

| От | Сообщение |
|----|-----------|
| терминал | `{type:"register", code}` |
| касса | `{type:"connect", code}` |
| касса | `{type:"pay", id, amount, currency}` / `{type:"cancel", id}` |
| терминал | `{type:"result", id, status:"success"\|"declined", reason?}` |

## Структура

```
build-windows.bat     сборка установщика .exe (Node.js + Inno Setup)
upload-github.bat     заливка на GitHub (APK собирается в Actions)
installer/            скрипт Inno Setup (FakePay.iss)
.github/workflows/    build-apk.yml — сборка APK
server/               релей-сервер (server.js, test.js)
desktop/              ПК-касса (main.js, index.html, styles.css, renderer.js)
mobile/               терминал (www/ — интерфейс, native/ — NFC-плагин, setup-android.js)
```

Батники сохранены в кодировке cp866 (русская консоль Windows). Если откроете их в редакторе и увидите «кракозябры» — не пересохраняйте в UTF-8, иначе текст в консоли поплывёт.

## Дальше можно добавить

Чеки и возвраты, несколько касс на один терминал, веб-хуки в ваш интернет-магазин, общую базу операций на сервере.
